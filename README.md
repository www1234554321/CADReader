# CADReader 網頁小程式 (CAD Reader & Mini-Editor)

一個基於 WebAssembly 與 HTML5 Canvas 技術的瀏覽器 CAD 閱讀、長度量測與微編輯工具。支援 `.dwg` 與 `.dxf` 格式平面圖。

## 🚀 專案功能特色

1. **CAD 檔案讀取 (`.dwg` / `.dxf`)**：
   - 採用瀏覽器端 WebAssembly (LibreDWG/dwgdxf) 解析 `.dwg` 檔，無需伺服器。
   - 解析線條 (Line)、多段線 (Polyline)、圓形 (Circle)、弧線 (Arc)、文字 (Text) 與圖層 (Layer) 結構。
   - 內建兩房一廳範例平面圖，開啟即用。

2. **視角與圖層控制**：
   - 滑鼠滾輪縮放、按住拖曳平移、一鍵全景 (Fit View)。
   - 深色 / 淺色背景畫布切換。
   - 圖層顯示 / 隱藏切換。

3. **量測與比例尺校準**：
   - **長度量測**：支援連續多點距離計算與頂點自動捕捉 (Snap)。
   - **面積量測**：多邊形封閉區域面積計算 (mm² / m²)。
   - **比例尺校準**：可自訂基準長度進行精準比例校對。

4. **簡單繪圖與編輯**：
   - 繪製直線、矩形、圓形與新增文字標籤。
   - 選取物件、移動、刪除物件，編輯文字內容與圖層屬性。
   - 一鍵匯出成 `.dxf` 檔案下載。

## 📦 本地開發與建置

```bash
# 安裝依賴
npm install

# 啟動本地開發伺服器
npm run dev

# 打包建置 (輸出至 docs 資料夾)
npm run build
```
